# How these task files work

Each file below is one agent's complete job description: mission, exactly
what to build, explicit do's and don'ts, a "definition of done" checklist,
and the first three concrete steps to take. Every agent reads only their own
file (plus the shared `AGENTS.md` and `CONTRACTS.md`).

- `01-backend-lead.md`
- `02-ai-data-lead.md`
- `03-frontend-lead.md`
- `04-ui-ux-lead.md`
- `05-realtime-integration-lead.md`
- `06-devops-qa-lead.md`

If a task file references another agent's output, it's referring to
`CONTRACTS.md` — never to that agent's actual code, which you shouldn't need
to read directly.
